# mermaid-hillchart-dsl

> [!NOTE]
> This is a private, internal package for the `mermaid-hillchart` workspace.

This package contains the Langium-based grammar definition and the generated parser for the Hill Chart language. It is consumed exclusively by the main diagram package to convert text input into an Abstract Syntax Tree (AST).

### Where to next?

- **For usage and installation:** See the [core diagram package](../diagram/README.md).
- **For grammar changes:** See [CONTRIBUTING.md](../../CONTRIBUTING.md#modifying-the-grammar) guide.
